### 路由與頁面結構 (SPA Route Flow)
本系統為**單頁面應用程式 (SPA)**，未導入 `react-router-dom` 套件，而是基於 `useState` 狀態來控制主要的步驟轉換：

```mermaid
graph TD
    App[App.jsx - 主入口] -->|step = 'landing'| LandingPage[LandingPage.jsx - 登入介紹首頁]
    LandingPage -->|點擊繼續| UploadZone[UploadZone.jsx - 圖片上傳]
    UploadZone -->|點擊開啟相機| CameraCapture[CameraCapture.jsx - 鏡頭捕捉]
    CameraCapture -->|成功拍攝| FacePreview[FacePreview.jsx - 人臉預覽/隱私同意]
    UploadZone -->|選擇本機圖片| FacePreview
    
    FacePreview -->|點擊分析 / 送出 API| FaceScanning[FaceScanningAnimation.jsx - 雷射掃描動畫]
    
    FaceScanning -->|API 回傳成功| ResultRoute[ErrorBoundary 錯誤防護]
    ResultRoute --> SkinAnalysisDashboard[SkinAnalysisDashboard.jsx - Bento 網格看板]
    
    SkinAnalysisDashboard -->|選取 Overview 區塊 / 切換 Tab| UniformityRadar[UniformityRadar.jsx - 均勻度雷達圖]
    SkinAnalysisDashboard -->|切換 Regions Tab| RegionCard[RegionCard.jsx - 五大分區膚況卡片]
    SkinAnalysisDashboard -->|切換 Regions Tab| ToneComparison[ToneComparison.jsx - 區間色差 delta 對比]
    SkinAnalysisDashboard -->|切換 Conditions Tab| ConditionsPanel[ConditionsPanel.jsx - Segformer 膚況分割]
    SkinAnalysisDashboard -->|切換 Recommendations Tab| Recommendations[Recommendations.jsx - 粉底液與 SPF 防護推薦]
```

*   **呼叫位置：** [api.js](file:///L:/Lumiere/Front_Lumiere/src/services/api.js#L20-L46)

#### Request 格式 (請求參數)
在前端封裝成 `FormData` 物件發送，同時配合語系代碼以 Query 參數傳輸：
| 參數名稱 | 位置 | 類型 | 說明 |

| `lang` | Query Param | `String` | 當前語系代碼（`en`、`tw`、`zh`、`pt`、`fr`、`tr`），供後端 AI Prompt 作為生成備註時的目標語言標示。 |

### 目標檢查欄位對照清冊
針對您提出的六個關鍵目標欄位，以下為目前 React 原始碼中的實際欄位名稱、所在結構階層，以及檢查結果：

1.  **`median_hex` (去背景中位數膚色 HEX 值)**
    *   *檢查結果：* **存在**。
    *   *實際名稱：* `median_hex`
    *   *階層路徑：* `result.skin_tone.median_hex`
    *   *說明：* 由 [SkinAnalysisDashboard.jsx](file:///L:/Lumiere/Front_Lumiere/src/components/SkinAnalysisDashboard/SkinAnalysisDashboard.jsx#L79-L93) 取出後傳入 [SkinToneCard.jsx](file:///L:/Lumiere/Front_Lumiere/src/components/SkinAnalysisDashboard/SkinToneCard.jsx)，用來繪製「Healthy Skin Tone」色塊，並與整體 Fitzpatrick Hex 色塊對應展示。

2.  **`undertone` (副色調)**
